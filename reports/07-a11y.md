# 07-a11y report

PR: https://github.com/itsOmidKarami/kraft/pull/765 (branch kraft/docs-a11y, into kraft/docs-design, label release::none)

## Summary
Skip-to-content link as the first Tab stop (Nitro `render:html` plugin, so it precedes the header and works without JS); one global 2px `:focus-visible` ring in the primary colour; the 404 now has Kraft-voiced copy ("No page at this address") baked into 404.html (the prerendered shell was an empty `#__nuxt`) and the same words in error.vue; code blocks that scroll sideways take focus (`ProsePre.vue`); separators are decorative (app.config `ui.separator.defaultVariants.decorative`, fixing the Edit/Report footer); sidebar navs labelled; the version banner is wrapped in a labelled region in the two layouts. axe is clean on all four page/viewport combinations afterwards.

## Decisions
- Skip link injected by a Nitro plugin, not a layout: the header renders before any layout, so only HTML written ahead of the app can be first in tab order.
- Focus ring in primary (violet), unlayered so it beats Nuxt UI's per-component rings; ~6:1 on white and on the dark page.
- Code-block tabindex only when the block overflows (measured in the browser, set on the `<pre>` directly because Nuxt UI also puts attrs on the wrapper); avoids dozens of useless tab stops.
- Footer "or" separator fixed site-wide by making every USeparator decorative, rather than copying Docus's whole page file.
- 404.html shell links to both release and next docs (one file serves / and /next/); the hydrated page keeps the channel-aware hint.
- Banner region done in layouts (not VersionBanner.vue, item 6's file); rendered only on the next channel so stable has no empty landmark.
- Kraft-i8ueh.8 does not reproduce: logo -> /next/, switch links /<page> and /next/<page>, no /next/next/.
